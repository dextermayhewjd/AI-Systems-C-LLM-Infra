Bellman backup 接收一个 当前估计的 V，输出一个 基于模型的一步期望回报（one-step lookahead）。

公式（你的实现对应这个）：

```math
B V(s,a)=R(s,a)+\gamma \sum_{s'}T(s,a,s')V(s')
```

注意：你这里写的是给定 state 和 action 的 backup（算的是一个 Q-like 的量），不是直接 max_a 的 optimal backup。


## 2. policy evaluation

```math
V_k^\pi(s) = \sum_a \pi(a|s) \Big[ R(s,a) + \gamma \sum_{s'} p(s'|s,a)\, V_{k-1}(s') \Big]
```

## 3. 接下来就是两个方向optimal policy 和 optimal value  

### 3.1 optimal policy的流程  

#### 3.1.1 policy improvement

对每个 state s，计算在“之后一直按照旧 V^π 的最优行为”下，各动作的 one-step lookahead 值，然后选最大动作作为新策略。
在用旧的 v^\pi作为“未来价值”的评估器，然后贪心改策略
#### 3.1.2 policy iteration

只需要R和T
奖励函数和转移概率  


1. 一开始的policy是随机的  

2. 然后按照当前的policy先确定 Value Function ： 使用policy evaluation  

3. 然后使用刚生成的Value function
来确定新的policy  
这一步使用
policy improvement来

4. 重复2-3的操作一边生成value function
一边重新计算policy
一边用新的policy来生成value function

直到迭代的过程策略不发生变化

### 3.2 value iteration
上面的policy iteration是策略不再变化的时候就停下来  

value iteration 先完全更形完value function

方法是bootstrap 默认旧值中每一步都是选择吗单步最优的情况下更新value function

理论上：无限 horizon（γ<1）对应“无限期折扣回报”  

然后在每一个state具体算该选哪个action的时候  
通过q state action 来选遍历所有action后选择回报最高的action
来获取policy

算法的具体实施就是先确定value function
然后一步步确定policy

## 区别

Policy Iteration：交替做“精确/近似的 𝑉𝜋

” + 贪心改策略，通常迭代次数少但每次 evaluation 成本高。

Value Iteration：每次只做一次 optimal backup（更便宜），但需要更多迭代才能收敛。
